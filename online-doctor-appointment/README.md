# VyasilaCare — Online Doctor Appointment

A web clone of an online doctor appointment booking system. Patients can browse specialists, pick a time slot, confirm a visit, and manage bookings in the browser.

## Features

- Landing page with featured clinicians
- Doctor directory with specialty filters and search
- Appointment booking with conflict-aware time slots
- My Appointments view with cancel support
- Local storage persistence (no backend required)

## Stack

- React 19
- Vite
- React Router

## Run locally

```bash
cd online-doctor-appointment
npm install
npm run dev
```

Open the URL printed by Vite (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
